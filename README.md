# 🃏 Jogo de Cartas — Super Poder

Projeto desenvolvido em **Python** utilizando **Programação Orientada a Objetos (POO)**, funções e manipulação de arquivos.

O jogo coloca **duas cartas em uma batalha**, onde cada carta representa uma cidade e possui os seguintes atributos:

* Estado
* Código
* Nome da cidade
* População
* PIB
* Área
* Pontos turísticos
* Densidade populacional
* PIB per capita

A partir desses atributos, é calculado o **Super Poder** da carta, utilizado para determinar o vencedor da batalha.

## 🎮 Menu

O jogo possui um menu com 5 opções:

```text
1 - Ver regras
2 - Cadastrar cartas
3 - Ver cartas cadastradas
4 - Batalhar
5 - Sair do jogo
```
